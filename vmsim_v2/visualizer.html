How to read these results

  • Same rules in both enginesThe TLB is invalidated when a page is evicted, and a TLB hit never bypasses the policy.
  • Cold vs capacity faultsA cold fault is a page’s first reference. Every later fault is a capacity fault.
  • Ties and randomnessOPT breaks ties on the smallest page number. The built-in Random uses its own seeded generator, so its numbers differ from Python’s.
  • Python-only extrasPrefetch and EAT need the Python engine: run python -m vmsim serve, then choose it under Engine.
